# 小欧探索模式「学具台」设计

日期：2026-08-14  
状态：实现中（体验分支 `cursor/explore-stage-d734`，先给家长试用再决定是否合入）  
产品：小欧手机 H5  
前置：`snap_grid` 学具已落地；主题芯片在 `cursor/h5-topic-polish-d734`

## 1. 问题

家长反馈探索模式「不好用」，三件事同时成立：

- 打开后不知道点哪，要等模型很久才出现能玩的东西。
- 能拖方块，但格子困在聊天气泡里，又小又会滚走，拖和滚屏抢手势。
- 整体仍像聊天软件，不像给约 8 岁孩子的学具。

颜色和主题按钮解决不了这三件。根因是：**探索的主界面仍是对话流，学具是气泡附件。**

## 2. 目标

探索模式改成：中间一块学具，上面一句老师的话。孩子打开后最多点一次「开始玩」，立刻能拖方块。

成功标准（体验时用）：

1. 探索空状态没有长欢迎词；正中有一颗大按钮「开始玩」。
2. 一点「开始玩」，不等模型返回，屏幕上就有可拖的 3×3。
3. 活盘固定在学具台，不随「对话」滚动；对话进单独底栏页。
4. 顶栏不再放「探索 / 带题」；带题从家长设置或「我有作业」进入。
5. 底栏默认只有「想跟小欧说」；「我卡住了」等收进「需要帮忙」。
6. 托盘显示「还剩 N 块」，可「收回」上一块；铺满先出现「摆好了」，再发给小欧。
7. 带题模式仍是现在的聊天（拍照、气泡）。
8. 不给答案、一次一个问题、模型只出 `xiaoou-draw` JSON、小程序零改动。

## 3. 已锁定的决策

| 项 | 决定 |
|---|---|
| 范围 | 只改 H5 探索模式的壳；带题保持聊天壳 |
| 聊天引擎 | 仍用现有 `web/app.js`，不改 React |
| 学具 | 仍是 Konva `snap_grid` + 静态 SVG 分流 |
| 出题 | 「开始玩」立刻本地挂 3×3，同时 `kickoff`；若模型也是 3×3 则保留孩子已摆的块 |
| 模式切换 | 从顶栏拿掉，放进家长设置；加号里提供「我有作业」 |
| 历史 | 探索里点「对话」看气泡；活盘只在学具台挂一份 Konva |
| 快捷句 | 探索里不横排展示；进「需要帮忙」 |
| 小程序 | 零改动 |

不在本期：关卡地图、星星、新学具类型、微信小程序可拖方块。

## 4. 界面结构

### 4.1 探索

```
[小欧]  主题 ▾                              ⚙

这 9 块，能摆成一个正方形吗？          对话

┌─────────────────────────────────────┐
│                                     │
│              学具台                  │
│         （活 snap_grid）             │
│                                     │
│     还剩 4 块              收回      │
└─────────────────────────────────────┘

需要帮忙                         想跟小欧说
```

空状态：学具台正中「开始玩」，旁白写「点开始玩，把方块拖进格子」。

点「想跟小欧说」才展开加号 / 输入框 / 麦克风 / 发送。

### 4.2 带题

现有顶栏（无模式开关）+ 消息列表 + 完整输入条。家长设置里可切回「一起探索」。

### 4.3 家长设置

增加「现在怎么玩」：一起探索 / 带题来问。切换仍会清空对话（与现在一致）。

## 5. 行为

### 5.1 开始玩

1. 隐藏空状态按钮。
2. 立刻在学具台挂 `cols:3 rows:3 tray:9` 的可拖盘。
3. 旁白改为「先随便摆摆，小欧马上出题。」
4. 调用现有 `kickoff` 流（不显示孩子气泡）。
5. 流式过程中旁白用去掉画图 JSON 后的口语文案；学具台不停、不卸盘。
6. 回复结束后：若新 `snap_grid` 与当前盘同规格，保留占用；若规格变了，换新盘；若只有静态图，学具台改挂那张 SVG。

### 5.2 活盘

- 只在 `#stageHost` 上 `mountSnapGrid(..., interactive: true)`。
- 「对话」里的历史气泡只留 SVG 占位，不再挂第二份 Konva。
- 学具台不随消息滚动，`touch-action: none`，避免和滚屏抢手势。
- 格子边长按学具台宽度计算，上限约 72px（比气泡里的 56px 更大）。

### 5.3 收回与计数

- 每次松手若位置变化，记一步。点「收回」把最后一块放回托盘。
- 「还剩 0 块」时文案为「方块用完了」。
- 收回若使「已铺满」不再成立，取消尚未发出的里程碑（沿用现有 400ms 防抖逻辑）。

### 5.4 摆好了

进入 `board_full` 时学具台短暂显示「摆好了」，再按原方案 C 把盘面发给小欧。不要无声跳一条新气泡作为唯一反馈。

### 5.5 恢复会话

探索模式若本地已有对话：不回空状态，旁白取最后一条老师口播，学具台按最后一次 `snap_grid` + `state.boards[0]` 恢复。

### 5.6 换一题

「需要帮忙」里提供「换一题」，等同再一次 `kickoff`。家长设置里的「开启新的探究」仍清空会话。

## 6. 文案规则

旁白从老师 Markdown 抽出：

- 去掉围栏代码块（含流式未闭合围栏）。
- 去掉以 `{` 开头且含 `"type"` 的裸 JSON 行。
- 去掉 `*` `` ` `` 等标记。
- 取开头一两句，大约不超过 90 字；抽空则保留上一句旁白。

空状态与开始玩的固定句见第 5 节，不解释「我不会直接给答案」。

## 7. 测试

- `tests/activity_state_test.js`：旁白抽取、还剩 N 块、两盘是否同规格。
- `tests/test_frontend_regressions.py`：学具台 DOM、模式开关不在顶栏、开始玩、对话/帮忙底栏、缓存戳。
- 现有 snap_grid 挂载 / 冻结 / 盘面附言测试保持通过。

## 8. 非目标

- 不把带题改成学具台。
- 不自动在每次打开页面时扣模型（必须点「开始玩」或已有会话）。
- 不把 API 密钥暴露到前端。
